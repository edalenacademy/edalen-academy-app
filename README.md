# Edalen Academy Android App

This Android project opens the existing Edalen Academy website inside a WebView:

https://edalenacademy.github.io/edalenacademy/#/login

## Build

The included GitHub Actions workflow builds a debug APK automatically after a push to `main`, or manually through the Actions tab.

The project is a WebView wrapper. The website and its Supabase/Backblaze functionality remain hosted by the existing web application.
